# Routes

This app uses **TanStack Router** file-based routing (client-side SPA, built with Vite).
Every `.tsx` file in this directory defines a route.

| File | URL |
| --- | --- |
| `index.tsx` | `/` |
| `about.tsx` | `/about` |
| `courses.index.tsx` | `/courses` |
| `courses.$slug.tsx` | `/courses/:slug` |
| `_authenticated/route.tsx` | layout guard for signed-in pages |
| `__root.tsx` | app shell (providers, error and 404 pages) |

`src/routeTree.gen.ts` is generated by the router plugin on `npm run dev` / `npm run build`.
Commit it, but never edit it by hand.

Per-page `<title>` and meta tags come from each route's `head()` and are rendered by
`<HeadContent />` in `__root.tsx`. Static tags live in `index.html`.
