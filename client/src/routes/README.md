# Routes

This app uses **TanStack Router** with **file-based routing** (generated by
`@tanstack/router-plugin`). Every `.tsx` file in this directory defines a route;
`routeTree.gen.ts` is generated automatically — do not edit it by hand.

The only root layout is `src/routes/__root.tsx`.

## Conventions

| File | URL |
| --- | --- |
| `index.tsx` | `/` |
| `courses.index.tsx` | `/courses` |
| `courses.$slug.tsx` | `/courses/:slug` |
| `learn.$courseSlug.$lessonSlug.tsx` | `/learn/:courseSlug/:lessonSlug` |
| `_authenticated/route.tsx` | layout guard (redirects to `/signin` without a token) |
| `_authenticated/dashboard.tsx` | `/dashboard` |

Routes fetch data from the Express API via the hooks in `src/lib/content.ts`
and the client in `src/lib/api.ts`. There is no server-side rendering; this is a
client-rendered SPA served as a PWA.
